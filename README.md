# Голем в подземелье (прототип)

Пошаговая карточная игра-подземелье с ресурс-менеджментом. Играет механический голем, у него три стата (физ, маг, ловк), HP, грузоподъёмность и два действия за ход. Один этаж, цель: найти выход.

## Как играть
1. Выбери сборку голема.
2. Каждый ход тяни комнату вслепую и ставь её рядом с любой выложенной.
3. Два действия за ход: разыграть карту, перейти в соседнюю комнату или призвать монстра из руки.
4. Новая комната: бросок d6 против её очков зла, при провале засада. Бой: d6 плюс стат против d6 плюс тот же стат врага.
5. За убитого монстра даются очки добра, которые тратятся на карты. Колода добра конечна.
